# Enemy Combat Systems — Volume 2

Each enemy folder contains its cleaned master state(s), six-frame power loops, an eight-frame firing cycle, four hit frames, eight death frames, a transparent atlas, GIF preview, fixed weapon anchors, collision bounds, VFX references and four attack-pattern definitions.

All gameplay sprites face down-screen. Spawn projectiles on attack frame 4. VFX stay independent from enemy art for collision, tinting and timing.
