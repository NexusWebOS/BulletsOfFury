# CF Fury Ship Pseudo-3D Vol.1

Bullets of Fury II player-ship production sprites for a third-person 6DOF/chase-camera game.

## Included

- 16 unique pitch views covering a full 360-degree forward somersault.
- Frame 01 is the neutral rear-chase view; it is also the maneuver entry/exit frame.
- 256x256 and 128x128 hard-alpha frame sets with 4x4 atlases and JSON.
- Four-frame twin-thruster overlay, kept separate from the ship body.
- Forward and reverse somersault playback definitions.
- Contact sheet, GIF previews, powered rear composite, audits, and browser lab.
- Exactly four recessed missiles: two under each wing. Rear views show only their tips/fins peeking beyond the trailing edges.

Sources are preserved separately from the runtime ZIP. Runtime assets contain no magenta, fringe, partial alpha, or hidden matte RGB.
