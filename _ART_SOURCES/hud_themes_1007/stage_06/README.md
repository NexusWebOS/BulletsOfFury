# STAGE_06 — Sky / rain

Storm-slate blue and brushed aviation silver, subtle rain beads on exposed metal, waterproof black gaskets, restrained electric-blue seam highlights. Boss endcaps have engraved angular lightning motifs and aircraft air-intake geometry; miniboss has compact wingtip fins and rain-channel vents. No clouds obscuring panels, no falling particles, NO caution stripes.

hud-kit-v2.png contains the player HUD, shielded boss, unshielded boss, shielded miniboss and unshielded miniboss, in that order. All long resource meters have continuous glowing fills. The sheet is generated concept art with sample values, not registered runtime sprites. See the parent README for integration details.
