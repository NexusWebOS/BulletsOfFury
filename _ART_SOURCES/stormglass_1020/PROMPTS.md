# Stormglass Academy — generation prompts

## Terrain concept — built-in image generation

Use case: stylized-concept. Production game asset: a BRAND NEW dedicated tutorial stage terrain plate for Bullets of Fury, a mid-1990s Neo Geo / Sega 32X vertical military science-fiction shooter. Scene: STORMGLASS ACADEMY, a secret floating flight proving ground built above a luminous dark teal ocean at sunrise. Strict straight-down orthographic aerial view, NO horizon, NO isometric perspective. Tall portrait scrolling map. Massive worn gunmetal academy flight decks, pale ivory hangar roofs, turquoise canal-like launch corridors, scattered circular turbine pools, radar dishes and service gantries along the LEFT and RIGHT outer quarters. Clearly readable wide open central flight lane with deep blue water and soft clouds underneath, controlled tiny warm amber marker lights. At different heights, alternating academy docks, open water and an elegant giant circular test gate embedded in architecture along the sides. Detailed crisp hand-placed pixel art, limited nuanced pixel palette, hard pixel clusters, restrained dithering, beautiful industrial metal texture. Keep central half relatively dark and low contrast so native bullets and ships remain legible. Top and bottom edges must both terminate in the SAME quiet dark teal water texture, so the image tiles vertically without a cut; no structures cut across those two edges. Full bleed edge to edge terrain, no frame. No aircraft, no characters, no ships, no enemies, no projectiles, no UI, no text, no labels, no fake game screenshot. This is the actual terrain artwork to be used underneath live gameplay. Portrait aspect ratio 1:2 if possible.

## Transparent architecture layer — built-in image generation edit

Edit this supplied game terrain into a production PARALLAX ARCHITECTURE LAYER. Keep the same tall portrait framing and the same placement, scale and design of every gunmetal academy platform, deck, white hangar, circular turbine, radar dish, gantry and structural support. Preserve the crisp mid 1990s pixel art appearance and metal detail. REMOVE THE ENTIRE OCEAN, all blue/teal water, all foam, all clouds, all atmosphere and all water shadows/reflections. Replace those removed pixels with GENUINE TRANSPARENCY, including water inside the circular turbine pools, underneath bridges and between platform supports. The result must be only solid academy machinery and architecture on transparent alpha, so a separately animated ocean and independent clouds can show through it at runtime. No backdrop of any color, no checkerboard pattern baked into the image, no sky, no ships, no characters, no text, no UI. Keep image aspect ratio 1:2 and whole structures at the same positions; preserve an empty transparent band along the top and bottom so this layer scrolls vertically.

The first opaque concept is retained only in this source archive. The shipped asset is the transparent architecture layer. Authored native ocean and cloud animation reels supply the independent parallax layers. There are no generated aircraft in the terrain.
