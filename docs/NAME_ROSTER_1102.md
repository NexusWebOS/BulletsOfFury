# Bullets of Fury - name roster

Every enemy, miniboss and boss in the current game, grouped by stage, so you can give them new human-sounding names.
Fill in the **New name** column. The **ID** column is the internal name in the code, so each entry can be found and renamed later.

Sources: the 154-card enemy field guide (regular enemies) and the game's own boss/miniboss list. Repeated cards for the same enemy are listed once; colour or attack variants that the guide names separately get their own row.
