# STAGE_03 — Ice

Frosted blue steel and pale silver bevels, restrained crystalline ice growing only along outer corner edges. Boss endcaps use faceted icy keystones; miniboss endcaps are compact hexagonal snowflake vents with little frost teeth. Keep all instrument recesses dark for readable text. NO caution stripes.
