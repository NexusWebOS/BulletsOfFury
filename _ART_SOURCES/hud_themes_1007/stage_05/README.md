# STAGE_05 — Space

Deep midnight-indigo spacecraft alloy, polished silver/chrome rail edges, a few inset cold-white navigation lights, restrained violet edge reflections. Boss endcaps use orbital-ring emblems around dark round reactor plugs; miniboss endcaps use compact faceted satellite radiator brackets. No background stars outside the frame and NO caution stripes.

hud-kit-v2.png contains the player HUD, shielded boss, unshielded boss, shielded miniboss and unshielded miniboss, in that order. All long resource meters have continuous glowing fills. The sheet is generated concept art with sample values, not registered runtime sprites. See the parent README for integration details.
