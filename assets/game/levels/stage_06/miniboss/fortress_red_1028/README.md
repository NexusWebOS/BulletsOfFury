# Fortress authored banks

Default export: Aseprite1.3.18.6-dev, nearest-neighbor, RGBA, fixed untrimmed cells. Runtime frame metadata is S6F28_ART in assets/fortress_red_1028.js. All pivots are cell centers. Smoke center is offset54px above a destroyed fan socket; fire is offset10px above. Fan and core families use the single fixed hull scale; effects/projectiles blit at their authored dimensions. Sequence durations are selected by native simulation time: fans16fps, bolts20fps, orbs18fps, core16fps, smoke/fire10fps. No additive blend is required.

To reproduce: prepare an empty staging folder with art/ and copy this directory's sources/ into it. Run Aseprite --batch --script-param work=<staging> --script-param repo=<repository root> --script <this directory>/author.lua. The preserved original hull and chain-lightning atlas are read from their existing repo paths; extracted orb/core/smoke/fire source snapshots resolve archived/packed sources and are preserved here with provenance in sources.json. Compare exported hashes with manifest.json before installing. The recipe saves both editable .aseprite frames and fixed PNG sheets; it never trims/deduplicates frames.
