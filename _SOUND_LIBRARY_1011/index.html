WHAT IS IN THIS FOLDER

bof/ — one sound per game need, as .wav (44.1 kHz stereo, −1 dBFS peak), .mp3 (112k, the game's format), .vgm (plays on real hardware / any VGM player) and .recipe.json (open it in ColeForge 7 → GENESIS CHIP → IMPORT to edit).
genres/ — the genre banks rendered the same way.
library.json — every file with its measurements and QA result.

IN COLEFORGE 7

Open the generator, switch to GENESIS CHIP. The library panel now has genre tabs — BULLETS OF FURY is selected by default and holds every sound on this page as a one-click preset, labelled with its status and reason. Click one to load and hear it, tweak it in the chip editor, then EXPORT WAV / VGM.

WIRING ONE INTO THE GAME (WHEN YOU CHOOSE)

Nothing is wired. To use a sound: copy its .mp3 into assets/game/shared/audio/sounds/, register the key in the code-owned BOFA.sfx block in game.js (not manifest.js — it is generated), give it a Snd.TAME row with a min retrigger gate, and point the call site at it. For a MISSING key, registering it under the exact name the code already calls (e.g. error, enemyDie) makes it audible with no call-site change.

LIMITS

The YM2612 cannot speak: voice lines, announcer calls and taunts are not in this library. The DAC channel can play a sampled voice, but that needs a recording, not a synth patch.
