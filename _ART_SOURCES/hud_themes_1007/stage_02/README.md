# STAGE_02 — Lava

Blackened forged iron and charcoal basalt armor, ember-orange seams contained inside edge cracks, copper rivets. Boss endcaps look like heavy furnace seals with a subtle molten core inset; miniboss endcaps use compact heat-sink fins and small rectangular exhaust slots. No free-standing flames, no scorched text, and NO caution stripes.

hud-kit-v2.png contains the player HUD, shielded boss, unshielded boss, shielded miniboss and unshielded miniboss, in that order. All long resource meters have continuous glowing fills. The sheet is generated concept art with sample values, not registered runtime sprites. See the parent README for integration details.
