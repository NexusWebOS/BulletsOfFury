# STAGE_08 — Alien void

Obsidian chitin fused with evil dark chromium, purple iridescent edges and restrained magenta veins contained in the frame. Boss endcaps use symmetrical alien rib plates and small black-violet crystalline eyes; miniboss uses sleeker curled chitin talons and elliptical organic sockets. Instrument interiors remain technical, rectangular and readable. No tentacles across fills, NO caution stripes.

hud-kit-v2.png contains the player HUD, shielded boss, unshielded boss, shielded miniboss and unshielded miniboss, in that order. All long resource meters have continuous glowing fills. The sheet is generated concept art with sample values, not registered runtime sprites. See the parent README for integration details.
