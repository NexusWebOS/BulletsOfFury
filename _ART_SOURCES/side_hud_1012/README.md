# Side HUD concept sources

Generated October 12, 2026 with built-in image_gen for Mike's concept review.
Five paired left/right 1024×1536 RGBA housing plates, preserving returned pixels
and alpha. `prompts.json` contains every exact request and the material reference;
`generation-record.json` identifies original saved outputs. `registration.json`
contains SHA-256 values and measured display wells.

Build registration with `_BUILD_SOURCE/build_side_hud_concepts_1012.py`.
The review in `docs/previews/side_hud_1012/` adds native icons and arcade text,
and composes actual game captures into a consistent full-height playfield.
See `docs/SIDE_HUD_CONCEPTS_1012.md`. Mike selected the vented Siege Console (4).
Its exact plate is installed by `build_siege_console_1012.py`; the live HUD
and verification are documented in `docs/SIEGE_CONSOLE_1012.md`.
