# levels/stage_01

`asset_index.json` lists physical files, logical frame keys, source textures and crops. A frame in an atlas is a crop, not a second PNG. Original pack names identify the owning art workflow.

Common weapons, sounds, fonts and effects are shared. Stage 8 copied forms also load their original donor-stage roots. Empty categories are intentional places for future owned assets.
