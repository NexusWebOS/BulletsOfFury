# STAGE_X — Coastal city

Coastal-defense naval blue and warm ivory painted armor, teal glass accents and restrained copper trim. Boss endcaps use geometric harbor/city skyline embossing and small port beacon lights; miniboss uses compact bridge-rivet brackets and navigation buoy emblems. Maritime city infrastructure rather than a jungle, keep dark instrument screens. NO caution stripes.

hud-kit-v2.png contains the player HUD, shielded boss, unshielded boss, shielded miniboss and unshielded miniboss, in that order. All long resource meters have continuous glowing fills. The sheet is generated concept art with sample values, not registered runtime sprites. See the parent README for integration details.
