# Original digital jungle / built-in image generation

Mode: built-in image_gen, new original background. No third-party game background was imported. Existing approved BOF helicopter artwork was deterministically re-authored offline for the smaller size, banked poses, faster rotor playback and aimed/recoiling pods.

Use case: stylized-concept. Production pixel-art background for Bullets of Fury, a polished 16-bit/Neo-Geo vertical scrolling shooter. Generate one original top-down DIGITAL JUNGLE arena, tall vertical composition, no characters, no aircraft, no UI, no words. Dense dark emerald and teal alien jungle foliage, immense twisted tree roots and fern canopies interwoven with subtle violet circuitry, tiny red data faults and luminous cyan circuit veins. It is a corrupted downloaded jungle, not a brown road or city. True overhead view with NO horizon and NO perspective vanishing point. Central 55 percent is a readable low-contrast shadowy moss-and-root clearing with scattered fine circuit seams, so red bullets can be seen; denser beautifully detailed plant clusters frame the outer margins. Crisp deliberate chunky pixel clusters, restrained dark palette, hard highlights, detailed high quality arcade background, no airbrushed softness, no bloom haze. Full bleed opaque scene, no text or decorative frame. Make the top and bottom edges visually compatible for looping vertical scrolling. Aspect ratio about 2:3.

Normalization: 680x1024 fixed native tile, with nearest-neighbor pixel clusters; offline wrap seam blend. Separate stored-alpha foreground canopy from the same original foliage, ground 12px/s and nearer canopy 28px/s. Wire palette exported for the existing arena download transition. No runtime scale, tint, rotation, animated image alpha or blend effects added.
