# Stage8 alien refit generation briefs / November1

Built-in image_gen produced22 selected transparent PNG sources. This ledger records normalized reproducible briefs, not a verbatim tool transcript. The selected output IDs and SHA256 values are preserved in generated-selection.json and generation.json.

Shared constraints: true transparent background; full unclipped silhouette; top-down arcade metal pixel-art style matching supplied game references; centered fixed pivot and one scale. Choose512x512 for a single subject, or eight equal even cells on a4x2 sheet for animation. No text, labels, shadows cast on a background, terrain, UI, glow blobs surrounding a hull, or unrelated objects. Final exports use even padded bank cells after alpha inspection.

Identity references: mm1003_impharrow.png (Imp), mm1003_furnacemaw.png (Warp), mm1003_bluehybrid.png (Blue Hybrid). Hunter uses stalker_identity.png directly, with no regenerated identity. The authored native jet and weapon reference exports in this folder supplied style guidance.
