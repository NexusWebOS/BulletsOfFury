# Exact pursuit-frame animation sources

Mike rejected the earlier eight-vertex approximation. These overlays use the existing Hard/Furious menu masters at their complete 912x512 backing resolution. The actual connected neutral-metal frame faces are selected from original pixels, with source landmarks on the raised top plates, top recesses, lower side offsets, upper side recesses, bottom tabs and bottom notches. Four cards times six landmarks are checked. Protected interior rectangles prevent connected background grid flecks from entering the overlay; they are safety masks, never rendered shapes. No polygon stroke defines the final contour.

Each retained 16-frame RGBA Aseprite-format file has a hidden locked original-reference layer and two visible layers: original-frame material and source-derived edge accents. Original metal luminance and bevel details remain in all sixteen authored green-to-white pulse phases. Aircraft, typography, LED colors and interior background are excluded. All visible alpha stays on the original selected metal pixels. Source timing is 62/63ms alternating, one second per loop; runtime and arrow use the same 16Hz menu clock.

Full source is 912x512. The existing game draws that menu in a fixed 456x256 logical box with SS=2 backing density. Registry density:2 applies the same fixed source-to-logical mapping to these overlays; on the checked native canvas every source pixel maps to one backing pixel. This is static UI registration, not animated scaling, resolution switching or frame resizing. Each bank uses fixed even 406x326 cells and one even crop/origin, with transparent safety margins. Four 8x2 pages are 3248x652 and fit 4096 texture limits. All64 cels remain separate.

Aseprite is not installed on this migrated host; no editor GUI/CLI use is claimed. Source files are authored to the official RGBA format with sRGB, layers, compressed/linked cels and tags. An independent decoder validates file/chunk boundaries, layers, dimensions, timing and exact visible composites. The supported subset is the current normal RGBA layer/compressed-and-linked-cel subset, not every Aseprite feature. Format reference: https://github.com/aseprite/aseprite/blob/main/docs/ase-file-specs.md

Default command: python _BUILD_SOURCE/pursuit_trace_exact_1115_build.py. It independently decodes retained .aseprite cels and exports PNG banks/registry. It does not rewrite sources. Explicit --author recreates the layered source from the original-pixel selection recipe and pulse palette, overwriting source edits intentionally. The source-format writer/decoder functions are reused from the preserved older build script. Source masks, original references, manifest and phase colors are retained here. All four pages, registry and four source files reproduce byte-for-byte on the default build.

Runtime owner: assets/city_rescue_1115.js, city16Trace. Registry: assets/pursuit_trace_art_1115.js. No canvas paths, runtime glow/filter/opacity pulse or animated transform. Existing arrow, selection input and native campaign route callbacks remain owners. See docs/PURSUIT_TRACE_EXACT_1115.md for native evidence.
