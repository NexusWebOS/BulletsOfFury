# STAGE_09 — Water space

Abyssal navy spacecraft metal with pearlescent silver and luminous turquoise trim, tiny contained bubble-like stars inside narrow glass rim inlays. Blend orbital technology with deep-water pressure hulls. Boss endcaps use circular sealed porthole emblems and wave-crest engraving; miniboss endcaps use smaller swept hydrodynamic fins and round pressure bolts. No water background, no giant bubbles, NO caution stripes.

hud-kit-v2.png contains the player HUD, shielded boss, unshielded boss, shielded miniboss and unshielded miniboss, in that order. All long resource meters have continuous glowing fills. The sheet is generated concept art with sample values, not registered runtime sprites. See the parent README for integration details.
