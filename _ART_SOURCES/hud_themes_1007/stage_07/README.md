# STAGE_07 — Sewer / toxic

Oxidized industrial copper and corroded dark iron, contained acid-green fluid windows and tiny slime beads at outside seams. Boss endcaps resemble sealed pipe valves and pressure flanges; miniboss endcaps resemble smaller filter canisters with a small biohazard emblem. Muted rusty metal keeps bright green maneuver bars readable. No spill across gauges and NO diagonal caution stripes.

hud-kit-v2.png contains the player HUD, shielded boss, unshielded boss, shielded miniboss and unshielded miniboss, in that order. All long resource meters have continuous glowing fills. The sheet is generated concept art with sample values, not registered runtime sprites. See the parent README for integration details.
