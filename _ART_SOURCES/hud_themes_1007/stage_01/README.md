# STAGE_01 — Jungle

Deep olive military metal, warm aged bronze edges, small moss seams and restrained vine wraps only on outer corners. Boss endcaps use embossed fern/leaf vent shapes and angular jungle armor; miniboss endcaps use smaller copper strap brackets and leaf-shaped vent cuts. Green framing must stay darker than the luminous maneuver bars. No warning triangles and NO diagonal caution stripes.

hud-kit-v2.png contains the player HUD, shielded boss, unshielded boss, shielded miniboss and unshielded miniboss, in that order. All long resource meters have continuous glowing fills. The sheet is generated concept art with sample values, not registered runtime sprites. See the parent README for integration details.
