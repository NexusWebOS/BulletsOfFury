The selected raw sheet is archived as `gpt_tornado_source.png`. It is 1254×1254, so it is not used directly as an atlas. Aseprite extracts measured row bands using common 244×250 crops and column pivots, applies one common nearest-pixel reduction with integer rounding, and exports sixteen even fixed cells with a common pivot. The editable animation is `tornado.aseprite`; `author.lua` owns extraction and export.

Other assets are source-derived in Aseprite: actual Herald modular body parts retain physical mounts; casts, raised claws, depth departures/arrivals and return turns have paired authored white-hit frames. Skull growth/impacts and ricochet chunks retain current ER28 source art. Red lightning balls reuse the Stage6 red 1015 lightning source. All new runtime rendering is fixed-cell source-over blitting.
