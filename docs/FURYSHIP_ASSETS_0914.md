## Verification and limitations

- `_BUILD_SOURCE/furyship_0914/build.py` owns extraction and normalization.
  A single scale is used across all views of each component and across the roll.
  The RGB core master uses magenta removal; other masters retain generated alpha.
  Engine source columns use inspected separators because generation did not obey
  equal column widths. No shipping atlas was repacked or overwritten.
- `_BUILD_SOURCE/furyship_0914/probe.py` loaded all **70 generated frames plus
  the approved reference** through XART and rendered them using the actual game
  canvas in Chromium. Seven screenshot sheets were inspected. Zero page,
  console or controlled-loop errors. This was an asset review, not gameplay.
- `_BUILD_SOURCE/furyship_0914/preview_probe.py` exercised all eleven viewer
  reels, pause and single-frame selection with zero browser errors.
- Proof: `docs/qa/furyship_assets_0914.json`. Screenshots and an assembly-effect
  preview GIF are under `_shots/furyship_0914/`.

**These are candidate assets, not an installed replacement.** The generated
top-down hull differs slightly from the exact approved source, particularly
its panels and engines. Exact component assembly sockets and the transition
between the original hull and generated roll remain to be resolved. Component
key views are present; intermediate tumble frames and a smooth assembly have
not been certified. The existing authored sixteen-frame somersault reel remains
unchanged and needs animation alignment. Nine pilot palettes, real sky/space
handoff integration, death/evasion verification and the `spcboy` legacy unlock
remain pending. SPACE-12 and SPACE-13 are partial, not complete.
