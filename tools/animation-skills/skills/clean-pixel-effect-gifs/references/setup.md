# Quickstart

Use Python 3.12 (64 bit). Create a virtual environment in the current workspace,
then use its Python to install this skill's `requirements.txt` and run
`scripts/clean_gif.py`. Resolve both paths relative to the installed skill folder,
not a historical user directory. The portable download also provides
`Setup-Animation-Tools.cmd` and a complete README; keep that extracted folder.
FFmpeg is optional for review MP4s. Raw inputs and outputs belong in the workspace.
