BOSS MODE - ART ASSET COLLECTION

Corrected Boss Mode branding only. Includes logo, cover, boot screen, loading frames and fills, windows/dividers, 48 button states, 16 cursors, 20 icons, 94 bitmap glyphs, and full-size standalone window.

Each category contains untouched source art, normalized magenta source where applicable, transparent individual PNGs, a rebuilt atlas, and a JSON map. Cover and boot artwork remain opaque. The standalone window retains its dark interior; exterior is transparent.

These are artwork exports, not an application implementation. Glyph images are not TTF/OTF fonts; font baselines/advances and cursor hotspots should be set for your target UI. Button labels and source crops are in the maps. Loading fills can be scaled to the empty frame opening and clipped to progress.

Superseded images carrying the removed subtitle and the superseded window sheet are excluded.
